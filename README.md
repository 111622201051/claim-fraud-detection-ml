# claim-fraud-detection-ml

Claim Fraud Detection ML is a machine learning-powered application designed to identify potentially fraudulent insurance claims based on claim and customer-related data. The system integrates a trained machine learning model with a Flask-based backend to provide automated fraud predictions.

The application includes a complete prediction workflow covering data preprocessing, feature selection, feature scaling, trained model loading, and real-time inference. Serialized ML artifacts such as the trained fraud detection model, scaler, and selected features are used to generate predictions without retraining the model during inference.

The project also includes a web-based interface, backend prediction logic, and producer-consumer components for handling application workflows. It demonstrates the integration of machine learning with Python backend development, enabling automated and scalable fraud detection.

Key Technologies: Python, Machine Learning, Flask, Scikit-learn, REST APIs, Joblib, HTML/CSS, and asynchronous producer-consumer processing.
